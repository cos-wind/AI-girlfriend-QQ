回复策略与主动互动

私聊按好感度分档、群聊按活跃度分档，决定回不回、回多快、回多长；主动机会在下方独立设置。数值分档在下方通栏面板里切换；单个对象的开关仍然在「用户中心」里逐个设置，这里的「对象例外」和它共用同一份名单。

数值分档

这里仅设置「收到消息怎么回」，主动机会不受好感档位限制。好感范围只填一次，切换面板只是换一个查看和修改的维度。表格从上往下就是门槛：数值落在哪一档就按那一档执行，档位停用即不回复。

按对方好感度命中一个档位。取消勾选“启用”表示这一档整体停用（这就是好感度门槛）。「目标字数」和「最多分条」只作为给模型的软引导（“约多少字”），不是死命令；填 0 表示不限制，留空表示保持原值。回复频率（每小时/每日上限、冷却）已移除——回不回只由对象模式和档位启用决定。

对象例外

什么时候需要加例外？

没列在这里的群聊按「通用回复设置」里的回复模式走。列进来之后，群聊可以在三种模式里选一个：
smart —— 被 @ 或命中触发词就回；被 @ 之后 5 分钟内这个人再说话不用重新 @（就是"续聊窗口"）。
mention —— 每一轮都要 @ 才回，续聊窗口也不放行，入群欢迎这类事件同样不发。
silence —— 沉默，只观察不回复（消息仍进记忆和总结）。
私聊对象没有 @ 的概念，仍用「跟随分档 / 强制允许 / 禁止回复 / 只记录」这四种。每小时的数字留空表示跟随分档，填 0 表示这一项不限制。「用户中心」里逐个开关的“允许聊天”写的也是这张名单。

本地服务（手动启动）

三个服务都不随桌宠 / NapCat 自动启动，只有在这里点击启动后才可用；不启动时不会产生任何空间网页请求，也不会刷新空间登录态。语音服务运行中时，同一个按钮会变成「停止语音服务」（会直接结束 8790 进程，正在进行的合成会被掐断）。运行状态统一显示在上方「运行状态」，卡片里不再重复显示。
