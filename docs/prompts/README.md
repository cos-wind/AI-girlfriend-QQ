# ATRI 提示词目录

这里是项目所有面向模型的静态提示词唯一维护位置。Python 代码只负责加载文件、填入运行时上下文和传递工具结果，不再保存人格或行为规则正文。

## 文件分层

- `atri_persona.md`：亚托莉人格、说话风格、原作背景和角色边界。
- `reply_contract.md`：回复长度、隐私、事实性和失败兜底规则。
- `language_guard.md`：输出语言和格式检查规则。
- `language_retry.md`：语言漂移或乱码时的重试规则。
- `rewrite.md`：答非所问、重复或模板化时的重写规则。
- `comfort_repair.md`：用户低落、疲惫、生气或纠错时的修复规则。
- `group_chat.md`：群聊参与、艾特、冷场和隐私边界。
- `lore.md`：原作设定触发和版权边界。
- `tool_use.md`：工具选择、联网搜索、网页阅读和失败处理。
- `visual_analysis.md`：OCR、图片、表情包和视频帧分析规则。
- `voice_policy.md`：语音合成工具的使用规则模板。
- `iteration.md`：用户纠错后的迭代规则。
- `scene_control.md`：私聊、群聊、情绪和原作话题的运行时模板。
- `proactive.md`：主动消息生成模板。
- `proactive_topic_rule.md`：主动消息的话题切入规则。

## 编辑原则

人格文件负责“她是谁以及怎么说话”；运行规则负责“什么能做、什么不能声称做过”。修改人格不会删除工具、隐私、视觉失败保护或群聊边界。涉及工具能力、隐私和安全的规则优先于角色扮演表达。
