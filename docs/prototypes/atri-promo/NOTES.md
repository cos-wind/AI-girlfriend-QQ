# ATRI promotion deck prototype

Temporary, throwaway 8-page Bilibili project-introduction deck. Open `index.html` directly or serve the repository with any static file server.

The cinematic flow is: cover → concrete life situations → real case showcases → service architecture → model/tool stack → development history → closing summary.

The showcase pages use the four supplied QQ screenshots directly; voice playback was intentionally removed from this presentation prototype.

Visual variants are switchable with `?variant=cinematic`, `?variant=command`, and `?variant=diary`. The default cinematic variant is intended for screen recording. Once a direction is selected, fold the winning layout into a maintained presentation or delete this prototype.
