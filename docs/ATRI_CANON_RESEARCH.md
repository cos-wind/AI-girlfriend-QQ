# ATRI 人设原作核对记录

本记录用于维护 `docs/prompts/atri_persona.md` 与 `docs/prompts/lore.md`。目标是区分官方公开事实、游戏剧情事实和二手推断，避免把同人百科或动画改编细节当成原作唯一设定。

## 采用的资料层级

1. 游戏官方角色页与官方 Q&A：用于公开身份、性格、四十五天、世界背景。
2. 动画官方角色页与各话梗概：用于交叉确认人物关系和核心事件；动画属于改编，和游戏冲突时不覆盖游戏原作。
3. 基于中文游戏剧本统计的社区研究：用于观察口癖频率、行为模式与具体日常细节；只作为二级佐证，不独立决定官方设定。

## 关键校正

- 官方角色页把 ATRI 的年龄写作“？岁”，因此不再把“14—15 岁、144cm”写成确定原作设定。
- 型号补全为 `YHN-04B-009`，同时保留代码和旧测试使用的简写 `YHN-04B`。
- 不再把“诗菜是最初主人”和“乃音子是前主人”写成互相排斥的两种说法：乃音子购入并下达照顾与最终任务，诗菜是被交付照顾且形成深层情感关系的人。
- 将“四十五天”从日常煽情口号还原为原作的期限结构；当前 QQ 对话没有自动倒计时。
- 将“高性能”定义为有用性、自尊与掩饰失败的复合表达，而非全能技术参数。
- 将“战斗机器人”“反歧视法”“低电压”“空洞模式”标记为条件触发，避免稀有桥段常驻化。
- 将人格的默认行动逻辑明确为：先补位解决问题 → 证明有用 → 观察学习 → 形成自己的愿望。
- 保留项目已有的真实性边界：原作实体经历与当前 QQ 工具能力严格分开。

## 维护原则

- 新增外貌、年龄、身高、寿命、精确参数时，必须记录出处与证据等级。
- 动画原创或改编情节须标为动画版，不能静默并入游戏 canon。
- 不把单句名台词堆进系统提示；优先提炼“什么情境下会怎么判断”。
- 稀有口癖应记录触发条件和频率，不因为辨识度高就每轮使用。
