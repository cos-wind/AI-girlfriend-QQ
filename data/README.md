# 本地数据目录

运行时按需创建数据目录。此发行版不包含真实账号、聊天、记忆、日志、音频或模型。

- `music/`：自行放入可使用的成品歌曲；文件名作为歌名，仅扫描本层音频文件。
- `stickers/<情绪>/`：自行放入有使用权限的表情图片。
- `voice/profiles/`、`voice/references/`：本机音色配置和参考音频。
- `accounts/`：本机账号注册表及隔离数据。
- `memory/`、`webui/`、`runtime/`、`cognition/`、`insights/`：运行时私有状态。

除公开词典模板外，这些目录全部被 Git 忽略，不应上传真实数据。
